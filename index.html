How it works

Three script tags and a URL. That's all it takes to add remote sync to annotate.js.

1

Load annotate.js

Drop the main annotate.js script into your page as usual.

2

Add sync plugins

Include sync-engine.js and your chosen backend (sync-google-sheet.js or sync-hono.js).

3

Configure the URL

Set data-google-sheet or data-hono-url on the script tag — or paste it when prompted in-app.
