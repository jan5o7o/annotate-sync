Sample Content to Annotate

This is a sample page for testing the Google Sheets sync plugin. Select any text on this page to highlight it and leave a comment. The annotation will be pushed to the shared Google Sheet in real time.

You can also draw rectangles (press R) or drop pins (press P) anywhere on the page. Each annotation carries a threaded comment that syncs automatically after a short debounce.

Feature: Section Notes

Click the + button in the toolbar to add a section note — a comment attached to this entire card rather than a specific text selection.

Feature: Freehand Drawing

Press F to switch to freehand ink mode. Draw directly on the page — perfect for circling layout issues or sketching ideas.
